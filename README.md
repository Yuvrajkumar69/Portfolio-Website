# Yuvraj Kumar — 3D Interactive Developer Portfolio

A modern, interactive 3D developer portfolio built to showcase my projects, technical skills, experience, and approach to creative web development.

The portfolio combines a professional developer profile with immersive 3D visuals, smooth animations, and interactive UI experiences.

- Interactive 3D developer portfolio
- Real-time 3D character experience
