## ✨ Overview

This portfolio is designed to present my development work through an interactive 3D experience while maintaining a clean and professional structure.

It combines React-based frontend development with Three.js, WebGL, and GSAP-powered animations to create an engaging experience across different sections of the portfolio.

- 🎭 Interactive 3D character experience

- 🎬 Smooth GSAP animations

⚙️ Getting Started
Prerequisites
Node.js
npm
Git
Clone the Repository
```bash
git clone https://github.com/Yuvrajkumar69/Portfolio-Website.git
cd Portfolio-Website
```
Install Dependencies
```bash
npm install
```
Start Development Server
```bash
npm run dev
```
---
🏗️ Production Build
```bash
npm run build
```
Preview the production build locally:
```bash
npm run preview
```
